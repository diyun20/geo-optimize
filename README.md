# GEO优化 — 生成式引擎优化系统

让品牌在 AI 搜索时代被更多人看到、说得更好。

## 核心功能

### 🔍 品牌检测
- 输入品牌关键词，检测在**豆包、DeepSeek**等主流 AI 平台的品牌提及率和排名
- 品牌扫描报告：关键词覆盖、平台分布、可见度分析
- 每日关键词统计，跟踪品牌曝光趋势

### 🔑 关键词管理
- 关键词批量蒸馏：AI 自动拓词，从种子词生成相关长尾词
- 关键词状态管理：启用/停用，灵活控制检测范围
- 支持手动添加关键词

### ✍️ AI 内容创作
- 文章一键生成：基于品牌信息 + 关键词，AI 自动撰写高质量文章
- 多风格支持：技术教程、观点评论、产品评测、故事叙述
- 文章发布管理，支持编辑后发布

### 📊 数据仪表盘
- 管理员/代理商/用户三级角色，权限分级
- 品牌可见度、关键词排名、文章数据一目了然
- 代理商专属数据：名下用户统计、消费趋势

### 👥 会员体系
- 试用/VIP 双层级，按功能区分权限
- 邀请返利机制
- 虚拟收录额度管理

### 🎬 更多工具
- 视频脚本一键生成
- 视频号分析
- 工单系统
- 自动任务调度

## 技术栈

PHP 8.2 · MySQL · Nginx · 宝塔面板 · 豆包/DeepSeek API

## 快速安装

1. 部署到宝塔面板 PHP 站点
2. 访问 `/installer/` 运行安装向导
3. 填写数据库信息完成安装
4. 默认管理员：`admin` / `123456`
