# GEO 文章多平台发布工具

## 简介
将 GEO 网站生成的 AI 文章一键发布到多个自媒体平台。

## 支持平台

| 平台 | 说明 |
|------|------|
| 小红书 | 图文发布 |
| 视频号 | 图文发布 |
| 抖音 | 图文发布 |
| 快手 | 图文发布 |
| B站 | 视频发布页 |
| 百家号 | 视频发布页 |
| TikTok | 视频发布 |
| Instagram | 图文发布 |
| Facebook | 图文发布 |

## 环境要求
- Windows 系统
- Python 3.10 或更高版本
- Chrome 浏览器（已安装）

## 使用步骤

### 第一步：安装
1. 双击 `install.bat`
2. 等待自动安装完成（约 1-2 分钟）
3. 看到 "安装完成" 提示即可

### 第二步：启动
1. 双击 `start.bat`
2. 浏览器将自动打开工具页面
3. 如果未自动打开，请访问 http://127.0.0.1:5410

### 第三步：登录账号
1. 在工具页面点击「账号管理」
2. 点击每个平台的「登录」按钮
3. 在弹出的浏览器窗口中扫码登录
4. 登录成功后会自动保存 Cookie

### 第四步：发布文章
1. 打开 GEO 网站 → 「文章多平台推送」
2. 选择文章和目标平台 → 点击「导出配置」
3. 下载 JSON 文件
4. 在工具页面点击「导入配置」→ 选择下载的 JSON
5. 切换到「发布中心」→ 点击「开始发布」

## 注意事项
- 首次登录需要扫码，后续无需重复登录
- 如果 Cookie 失效，需重新登录
- 发布过程中请不要关闭浏览器窗口
- 海外平台（TikTok/Instagram/Facebook）需网络环境支持

## 常见问题

**Q: 双击 install.bat 后没反应？**
A: 右键点击 install.bat，选择「以管理员身份运行」

**Q: 提示 "Python 未检测到"？**
A: 去 python.org 下载 Python 3.10+，安装时勾选 "Add Python to PATH"

**Q: 登录时浏览器没打开？**
A: 确保 Chrome 浏览器已安装，或检查杀毒软件是否拦截

**Q: 发布失败怎么办？**
A: 检查「账号管理」中对应平台的 Cookie 是否有效，无效则重新登录
