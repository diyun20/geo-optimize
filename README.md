## 核心功能

### 🔍 品牌检测
- 输入品牌关键词，检测在**豆包、DeepSeek**等主流 AI 平台的品牌提及率和排名
- 品牌扫描报告：关键词覆盖、平台分布、可见度分析
- 每日关键词统计，跟踪品牌曝光趋势

### 🔑 关键词管理
- 关键词批量蒸馏：AI 自动拓词，从种子词生成相关长尾词
- 关键词状态管理：启用/停用，灵活控制检测范围
- 支持手动添加关键词

### ✍️ AI 内容创作
- 文章一键生成：基于品牌信息 + 关键词，AI 自动撰写高质量文章
- 多风格支持：技术教程、观点评论、产品评测、故事叙述
- 文章发布管理，支持编辑后发布

### 📊 数据仪表盘
- 管理员/代理商/用户三级角色，权限分级
- 品牌可见度、关键词排名、文章数据一目了然
- 代理商专属数据：名下用户统计、消费趋势

### 👥 会员体系
- 试用/VIP 双层级，按功能区分权限
- 邀请返利机制
- 虚拟收录额度管理

### 🎬 更多工具
- 视频脚本一键生成
- 视频号分析
- 工单系统
- 自动任务调度

##GEO优化 - 安装教程
=================

##环境要求
--------
- PHP 8.0+
- MySQL 5.7+
- 支持 curl、pdo_mysql 扩展

##安装步骤
--------

1. 上传文件
将项目所有文件上传到网站根目录

2. 修改数据库配置
编辑 config/database.php，填入你的数据库信息：
'host' => 'localhost',
'dbname' => '你的数据库名',
'username' => '你的数据库用户名',
'password' => '你的数据库密码',

3. 请删除 storage/installed.lock 文件。

4. 访问网站
在浏览器中访问你的域名，进入程序安装页

6. 默认管理员账号
用户名：admin
密　码：123456

建议登录后立即修改密码

##宝塔计划任务
-执行周期：1分钟
-URL地址：http://你的域名/cron_worker.php?key=geo_cron_2024
